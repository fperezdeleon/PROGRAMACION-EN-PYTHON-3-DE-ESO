Imprímela: es lo único que puedes llevar a la prueba.

Mostrar y comentar

# comentario
print("Hola")
print(f"{nombre} tiene {edad} años")

Variables y tipos

n = 3        # int
x = 2.5      # float
t = "hola"   # str
ok = True    # bool

Operadores

+  -  *  /  //  %  **
7 // 2 → 3    7 % 2 → 1    2 ** 3 → 8
round(3.14159, 2) → 3.14

Pedir datos

nombre = input("Nombre: ")
edad = int(input("Edad: "))
precio = float(input("Precio: "))

Condicionales

if a > b and a > 0:
    ...
elif a == b or not (a < 0):
    ...
else:
    ...

Bucle for

for i in range(1, 6): ...        # 1..5
for i in range(10, 0, -1): ...   # 10..1
for i in range(0, 11, 2): ...    # pares

Bucle while

n = 10
while n > 0:
    n = n - 3
# ¡cambia algo dentro o será infinito!

Acumulador y contador

suma = 0
cuenta = 0
for i in range(1, 11):
    suma = suma + i
    if i % 2 == 0:
        cuenta = cuenta + 1

Bucles anidados

for i in range(3):
    for j in range(i + 1):
        print("*", end="")
    print()

Funciones

def area(base, altura):
    return base * altura

print(area(3, 4))

Cadenas

t = "Python"
len(t)  t.upper()  t.lower()  t[0]  t[-1]  "y" in t

Errores comunes

SyntaxError    → falta un :, una comilla o un paréntesis
NameError      → nombre mal escrito (¿mayúsculas?)
IndentationError → falta la sangría
TypeError      → mezclas texto y número (¿falta int()?)
