🧩 Misión 2: Mi primer programa en Scratch

🎯 Hoy aprenderás a…
  • crear un programa con entrada, decisión y repetición en bloques
  • usar variables en un lenguaje de bloques
  • generalizar un programa para que funcione con cualquier dato

📖 Teoría exprés

Hoy construyes un programa completo en Scratch que luego traducirás a Python (sesión 3). Tendrá las tres estructuras básicas:

EstructuraBloque de ScratchPara qué sirve
Secuenciauna instrucción debajo de otraEjecutar en orden
Condicionalsi … entonces / si noDecidir según una condición
Buclerepetir n vecesRepetir sin copiar
Entradapreguntar … y esperar → variable respuestaPedir un dato al usuario
Salidadecir …Mostrar un resultado
  • Variable: caja con nombre que guarda un dato (en Scratch: «Variables → Crear una variable»).
  • Generalizar: que el programa funcione con cualquier dato, no solo con el de tu prueba.
  • Se puede anidar: un si dentro de un repetir.

🔍 Ejemplos

El programa «Saludador» (en pseudobloques)

preguntar «¿Cómo te llamas?» y esperar
guardar respuesta en la variable nombre
decir (unir «Hola, » nombre)
preguntar «¿Cuántos años tienes?» y esperar
si respuesta > 17 entonces
    decir «Eres mayor de edad»
si no
    decir «Eres menor de edad»
repetir 3 veces
    decir «¡Programar mola!» durante 1 segundo

🚀 Misión de entrega

Taller de Scratch: el Saludador

Abre el editor de Scratch (no necesita cuenta) y crea un programa que:

  1. Pregunte el nombre y diga «Hola, nombre».
  2. Pregunte la edad y diga si es mayor o menor de edad (usa si … si no).
  3. Repita 3 veces «¡Programar mola!».
  4. Generaliza: añade una variable veces con el número de repeticiones y usa esa variable dentro del bucle.

Prueba el programa con dos nombres y dos edades distintas (por ejemplo, 17 y 18) para comprobar que funciona siempre.

📦 Qué entregas: una captura de pantalla de tu programa de bloques completo y el archivo saludador.sb3 (Archivo → Guardar en tu computadora), en Google Classroom.

⚖️ Criterio evaluado (solo uno): Criterio 2.1 · Resolver problemas desarrollando un programa informático y generalizando las soluciones.

✅ Se valora:

  • El programa resuelve lo que pide (entrada, decisión, bucle)
  • Usa una variable para generalizar el número de repeticiones
  • Funciona con distintos datos
  • Los bloques están ordenados y el programa es legible
