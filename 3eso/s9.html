🧰 Misión 9: Funciones y cadenas

🎯 Hoy aprenderás a…
  • crear tus propias funciones con parámetros y return
  • reutilizar código llamando a una función
  • manipular textos con len(), upper(), lower() y los índices

📖 Teoría exprés

Una función es un bloque de código con nombre que puedes usar muchas veces. Así generalizas y evitas repetir.

def saludar(nombre):
    print(f"Hola, {nombre}")

saludar("Ana")
saludar("Luis")
Hola, Ana
Hola, Luis
  • def nombre(parámetros): define la función; se ejecuta solo cuando la llamas.
  • return devuelve un resultado: x = area(3, 4).
  • Cadenas: len(t) longitud · t.upper() / t.lower() · t[0] primera letra · t[-1] última · "a" in t comprueba si está.

🔍 Ejemplos

Función que devuelve un valor

def area_rectangulo(base, altura):
    return base * altura

print(area_rectangulo(3, 4))
12

Cadenas

palabra = "Python"
print(len(palabra), palabra.upper(), palabra[0], palabra[-1])
