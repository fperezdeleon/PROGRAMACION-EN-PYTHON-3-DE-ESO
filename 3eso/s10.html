⚡ Entrenamiento tipo Parte A

¿Qué vale 20 % 6?

💡 20 = 3·6 + 2.

¿Qué muestra? x = 0 / while x < 3: x = x + 1 / print(x)

💡 Se detiene cuando x vale 3.

¿Cuántas veces se ejecuta el print? for i in range(3): for j in range(2): print(i, j)

💡 3 × 2 = 6.

¿Qué devuelve len("hola mundo")?

💡 Cuenta también el espacio: 10.

💻 Entrenamiento tipo Parte B

Estos ejercicios no son los de la prueba, pero se parecen. Inténtalos antes de mirar la solución.

Entrenamiento 1

Pide la base y la altura de un triángulo y muestra su área con una f-string.

Ver una solución
b = float(input("Base: "))
h = float(input("Altura: "))
print(f"Área: {b * h / 2}")

Entrenamiento 2

Pide una edad: menos de 12 → «Entrada infantil»; de 12 a 64 → «Entrada normal»; 65 o más → «Entrada jubilado».

Ver una solución
edad = int(input("Edad: "))
if edad < 12:
    print("Entrada infantil")
elif edad < 65:
    print("Entrada normal")
else:
    print("Entrada jubilado")

Entrenamiento 3

Pide una contraseña hasta que se escriba «python».

Ver una solución
clave = input("Contraseña: ")
while clave != "python":
    clave = input("Incorrecta. Otra vez: ")
print("Acceso concedido")

Entrenamiento 4

Crea la función cuadrado(n) que devuelva n al cuadrado y úsala con un número pedido.

Ver una solución
def cuadrado(n):
    return n * n

x = int(input("Número: "))
print(cuadrado(x))
