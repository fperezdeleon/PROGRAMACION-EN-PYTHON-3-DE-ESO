🧠 Misión 1: Pensar como un programa

🎯 Hoy aprenderás a…
  • explicar qué es un algoritmo y cómo se convierte en programa
  • distinguir entrada, proceso y salida
  • comparar lenguajes de bloques y de texto
  • seguir un programa de bloques con bucle

📖 Teoría exprés

Programar es dar instrucciones precisas a una máquina. Antes de escribir una línea hay que pensar el algoritmo: los pasos ordenados que resuelven el problema.

  • Algoritmo: secuencia finita y ordenada de pasos. Puede escribirse en lenguaje natural, en pseudocódigo o en un diagrama de flujo.
  • Programa: algoritmo traducido a un lenguaje de programación. Lenguaje visual (Scratch, Coding for Kids): bloques. Lenguaje textual (Python): se escribe.
  • Ventajas de los bloques: sin errores de escritura, muy visual. Inconvenientes: lentos para programas grandes y menos potentes. Por eso los programadores profesionales usan texto.
  • Secuencia: se ejecuta línea a línea, de arriba abajo. El orden cambia el resultado.

🔍 Ejemplos

Pseudocódigo: ¿número positivo o negativo?

1. Pedir un número
2. Si el número es mayor que 0 → mostrar «positivo»
3. Si es menor que 0 → mostrar «negativo»
4. Si no → mostrar «es cero»

Programa de bloques con un bucle

repetir 3 veces
    avanzar 2
    girar derecha

🚀 Misión de entrega

Ficha del Agente Algoritmo

Parte A · Juega. Completa al menos 6 niveles seguidos en Coding for Kids y captura la pantalla final de cada uno.

Parte B · Ficha.

  1. Ordena el algoritmo «Hacer una llamada»: A) Hablar · B) Marcar el número · C) Colgar · D) Esperar a que contesten · E) Coger el teléfono.
  2. Sigue el programa. Tablero de 6×6. El robot está en la casilla (2, 2) mirando hacia arriba. Programa: repetir 3 veces: avanzar 2, girar derecha. ¿En qué casilla acaba y hacia dónde mira? Dibuja el recorrido.
  3. Pseudocódigo. Escribe el algoritmo para decidir si una persona puede entrar a un parque (entra gratis si tiene menos de 5 años; si no, paga).
  4. Reflexiona. Escribe una ventaja y un inconveniente de programar con bloques frente a hacerlo con texto.

📦 Qué entregas: un documento de texto con las respuestas y las capturas, en Google Classroom (mision1_tunombre).
