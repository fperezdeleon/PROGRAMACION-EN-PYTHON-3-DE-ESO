🚦 Misión 6: Condicionales

🎯 Hoy aprenderás a…
  • usar if, elif y else
  • combinar condiciones con and, or y not
  • cubrir todos los casos, también los límite

📖 Teoría exprés

OperadorSignifica
== !=igual / distinto
< > <= >=comparaciones
andse cumplen las dos condiciones
orse cumple al menos una
notniega la condición
  • = guarda; == compara.
  • elif encadena condiciones; solo se ejecuta la primera que se cumpla. else recoge lo demás.
  • Los textos también se comparan: if clave == "python":.
  • Se pueden anidar condicionales (un if dentro de otro) sangrando de nuevo.
  • Prueba siempre los valores límite: si la condición es >= 18, prueba 17, 18 y 19.

🔍 Ejemplos

elif

nota = float(input("Nota: "))
if nota < 5:
    print("Suspenso")
elif nota < 7:
    print("Aprobado")
elif nota < 9:
    print("Notable")
else:
    print("Sobresaliente")
Nota: 7
Notable

and / or

edad = int(input("Edad: "))
if edad >= 12 and edad <= 17:
    print("Adolescente")
else:
    print("Otra etapa")
Edad: 14
Adolescente

⚡ Minireto (autocorrección, no cuenta para nota)

¿Qué muestra? x = 8 / if x > 5 and x < 7: print("A") else: print("B")

💡 8 > 5 es cierto pero 8 < 7 es falso; and exige las dos.

¿Qué muestra? x = 3 / if x < 2 or x > 5: print("A") else: print("B")

💡 Ninguna de las dos condiciones es cierta.

Si varios elif son ciertos, ¿cuántos se ejecutan?

💡 En cuanto uno se cumple, Python salta el resto de la cadena.
