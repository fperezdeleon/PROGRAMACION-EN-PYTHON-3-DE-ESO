🎒 Misión 4: Datos, operaciones y variables

🎯 Hoy aprenderás a…
  • guardar datos en variables de distintos tipos
  • usar los operadores aritméticos, incluidos // y %
  • mostrar resultados con f-strings

📖 Teoría exprés

TipoQué guardaEjemplo
intEnterosvidas = 3
floatDecimales (con punto)precio = 2.5
strTextonombre = "Lucía"
boolVerdadero o falsoactivo = True
OperadorSignificaEjemplo
+ - *suma, resta, producto3 * 4 → 12
/división (siempre da decimal)7 / 2 → 3.5
//división entera7 // 2 → 3
%resto7 % 2 → 1
**potencia2 ** 3 → 8
  • Asignar: x = x + 1 lee «nuevo x = x anterior + 1».
  • f-string: print(f"Total: {precio * unidades} €") mete valores dentro del texto.
  • round(numero, 2) redondea a 2 decimales.
  • Nombres claros y sin espacios: precio_total.

🔍 Ejemplos

f-string

nombre = "Lucía"
edad = 14
print(f"{nombre} tiene {edad} años")
Lucía tiene 14 años

División entera y resto

minutos = 135
print(minutos // 60, "h y", minutos % 60, "min")
2 h y 15 min

Redondear

media = (7 + 8 + 6) / 3
print(round(media, 2))
7.0

⚡ Minireto (autocorrección, no cuenta para nota)

¿Cuánto vale 17 % 5?

💡 17 = 3·5 + 2, el resto es 2.

¿Cuánto vale 17 // 5?

💡 La división entera se queda solo con la parte entera: 3.

¿Qué tipo de dato es True?

💡 True y False son bool (booleanos).

🚀 Misión de entrega

La tienda de gadgets

Crea tarea4.py con tres programas (comenta cada uno con su número). Usa variables y f-strings.

  1. Precio con IVA. precio = 20 y iva = 21 (%). Muestra el precio final con IVA, redondeado a 2 decimales (24.2).
  2. Reloj. segundos = 7385. Muestra cuántas horas, minutos y segundos son (2 h 3 min 5 s) usando // y %.
  3. Media. Guarda tres notas (7, 8.5 y 6) y muestra la media con dos decimales.

Generaliza: cambia solo los valores iniciales y comprueba que los resultados siguen siendo correctos.

📦 Qué entregas: el archivo tarea4.py en Google Classroom.

⚖️ Criterio evaluado (solo uno): Criterio 2.1 · Resolver problemas desarrollando un programa informático y generalizando las soluciones.

✅ Se valora:

  • Los resultados son correctos (24.2 · 2 h 3 min 5 s · 7.17)
  • Usa variables y los operadores adecuados (//, %)
  • Funciona al cambiar los datos iniciales
  • Salida con f-strings y comentarios
