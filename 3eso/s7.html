🔄 Misión 7: Bucles for

🎯 Hoy aprenderás a…
  • repetir con for y range()
  • usar contadores y acumuladores
  • combinar un if dentro de un for

📖 Teoría exprés

  • for i in range(5): → i = 0, 1, 2, 3, 4.
  • range(1, 6) → 1 a 5. range(2, 11, 2) → de 2 en 2 hasta el 10. range(10, 0, -1) → cuenta atrás.
  • Acumulador: variable que suma en cada vuelta (suma = suma + i). Contador: cuenta cuántas veces ocurre algo (pares = pares + 1).
  • Se puede poner un if dentro de un for (sangrando de nuevo).
  • Los bucles tienen una variable que cambia en cada vuelta; haz una tabla de seguimiento si dudas.

🔍 Ejemplos

Tabla del 3

for i in range(1, 11):
    print(f"3 x {i} = {3 * i}")
3 x 1 = 3
3 x 2 = 6
...
3 x 10 = 30

Cuenta atrás

for i in range(3, 0, -1):
    print(i)
print("¡Despegue!")
3
2
1
¡Despegue!

Contador con if

pares = 0
for i in range(1, 11):
    if i % 2 == 0:
        pares = pares + 1
print(pares)
5

⚡ Minireto (autocorrección, no cuenta para nota)

¿Qué valores toma i en range(3, 12, 3)?

💡 De 3 en 3 sin llegar al 12.

Para sumar los números de 1 a 100 usarías…

💡 suma = suma + i en cada vuelta.

¿Cuántas veces se ejecuta print en for i in range(2, 8): print(i)?

💡 Valores 2, 3, 4, 5, 6 y 7: son 6.
